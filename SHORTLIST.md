## ⚠ One condition must be settled before buying anything

iStock's licence forbids using an image in any way that lets others download
it as a standalone file. This site's code is **public on GitHub**, and the
site is deployed from it. Anything the site shows — including the graded copy
— sits in that public repository, where anyone can download it on its own.

So a purchased stock image cannot go into the site as it is built today. One
of these must come first, and each is the client's call:

1. **Make the GitHub repository private.** The simplest option. The live
   website is unaffected.
2. **Serve stock images from a private asset store** outside the repository.
   This needs new hosting set up, which is a separate decision.

Until then, the free-licence pool and photographers' permissions (see
`PHOTOGRAPHERS.md`) are the routes that work.

The same caution applies to **Pixabay** frames. Its licence forbids
distributing its images on a standalone basis, and a colour grade leaves a
photograph substantially the same. Pixabay frames found in the free hunt are
therefore **held**, not shipped, under the same condition.

## The licence, in plain words

Read in full at [istockphoto.com/legal/license-agreement](https://www.istockphoto.com/legal/license-agreement)
(last updated July 2026).

- **Commercial websites are a permitted use.** So are social media and
  advertising.
- **The rights last.** They are perpetual and worldwide, and survive a
  cancelled subscription for images already downloaded.
- **No limit on web views.** There is only a cap of 500,000 printed copies.
- **Editorial-only images can't be used commercially.** None of the picks is
  one.
- **No photo credit is required** for commercial use.
- **Single user.** A subscription is tied to one named person. Credits can be
  shared inside the company, one person at a time. Storing a file where
  several people can reach it at once needs the Extended licence.
- **Buy on the company's own account.** Buying for a client is allowed, but
  it is cleanest if Routes Crete buys in its own name.
